# HP Govt Jobs Finder — Starter UI

A free, responsive HTML/CSS/JavaScript starter interface for the HP Govt Jobs Finder project.

## Run it
1. Extract the ZIP.
2. Open the `HP-Govt-Jobs-Finder` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Navigate through the sidebar, save demo jobs, and try the profile form.

## Project structure
- `index.html` — page structure
- `css/style.css` — responsive styling
- `js/jobs.js` — illustrative sample job records
- `js/app.js` — navigation, rendering, search, filters, local saved jobs/profile
- `assets/` — reserved for logos and other local assets

## Important
The job records in `js/jobs.js` are fictional/illustrative sample data for interface testing. They are not verified current vacancies. Dates, eligibility and links must be checked against official recruitment notifications. The current app does not yet connect to HPPSC, HPRCA, Google Sheets, or any live job source. That will be a later integration step.

Google Fonts are loaded from the internet; the interface otherwise works locally.
